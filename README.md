# Abhishek Kumar Portfolio

A premium, responsive personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, GSAP, React Icons, tsParticles, and FormSubmit contact wiring.

## Setup

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Easy Edits

- Update portfolio content in `src/data/portfolioData.js`.
- Replace placeholder assets in `public/assets/`.
- Add your resume at `public/assets/Abhishek-Kumar-Resume.pdf`.
- Contact messages are sent to `work.abhishek06@gmail.com` through FormSubmit in `src/components/sections/Contact.jsx`.
- On the first real message, FormSubmit may send a confirmation email. Confirm it once to activate delivery.
